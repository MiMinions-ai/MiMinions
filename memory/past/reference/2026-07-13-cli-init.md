## Task

Introduce CLI subcommand `miminions init` as an explicit bootstrap/repair command with `--force` support.

## Decisions

- Added `force` parameter to `ensure_default_setup` to re-run default workspace/agent bootstrap when requested.
- Kept force mode non-destructive for templates by relying on existing `init_workspace(..., overwrite=False)` path.
- Added thin CLI command `miminions init` in `main.py` that delegates to `ensure_default_setup(..., force=...)`.
- Added tests for both core force repair behavior and CLI command behavior.
