# About MiMinions

- :material-check-circle: Provide composable building blocks for multi-agent systems

- :material-check-circle: Offer three-tier plus vector [memory](for-dev/modules/memory.md) so agents accumulate context over time
- :material-check-circle: Ship a local-first [CLI](for-use/cli.md) that keeps your data on your machine
