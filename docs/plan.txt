## 4. Host on AWS Amplify
- Open AWS Amplify in the AWS Console and select "Host web app".
- Connect this repository and select the branch to deploy from (`main` or `development`).
- Configure Build Settings (Amplify will suggest an `amplify.yml` — use this):
  ```yaml
  version: 1
  frontend:
    phases:
      preBuild:
        commands:
          - pip install mkdocs-material
      build:
        commands:
          - mkdocs build
    artifacts:
      baseDirectory: site
      files:
        - '**/*'
    cache:
      paths: []
  ```
- Save and deploy to get the initial Amplify URL.
- NOTE: `site/` is generated by Amplify at build time — never commit it.
- NOTE: Amplify automatically redeploys every time the connected branch receives
  a push — no GitHub Actions workflow needed.

## 5. Domain Management
- In the AWS Amplify console for the app, go to "Domain management".
- Add your desired custom subdomain (e.g., `docs.miminions.ai`).
- Update your DNS provider (e.g., Route 53) by adding the CNAME records provided
  by Amplify so traffic routes correctly, and wait for SSL validation.

## 6. Link from Main Website (Elastic Beanstalk)
- In the main website's codebase (`miminions_website`), update the primary navigation or footer.
- Add a new "Documentation" link with the `href` pointing to `https://docs.miminions.ai`.
- Deploy the updated main website repo to Elastic Beanstalk.
